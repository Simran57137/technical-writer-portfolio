# Managing Storagep

After creating storage, you can manage its configuration and lifecycle based on your workload requirements.

Available operations may include:

* **View** storage details and configuration.
* **Expand** storage capacity when additional space is required.
* **Manage Access** to control access to the storage.
* **Delete** storage when it is no longer required.

To manage storage, follow these steps:

1. Navigate to **Storage > File Storage**.
2. Locate the storage resource you want to manage.
3. Click the **Actions** tab.
4. Select the required operation.
5. Review the configuration or confirmation message, if displayed.
6. Click **Confirm** to proceed.

The selected operation is performed on the storage resource.
