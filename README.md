# Overview

Nimbus Cloud Platform provides a unified environment for setting up and managing cloud resources. This guide introduces the core networking, compute, and storage capabilities available on the platform.

With Nimbus Cloud Platform, you can create a **Virtual Private Network**, configure **subnet tiers**, deploy and manage **virtual machines**, and provision **file storage** for your workloads.

This guide covers the following:

* **Networking:** Create a Virtual Private Network and configure subnet tiers.
* **Compute:** Create virtual machines and manage their operations.
* **Storage:** Create and manage file storage for your workloads.
