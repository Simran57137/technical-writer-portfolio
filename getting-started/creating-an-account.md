# Creating an Account

To start utilising the Nimbus Cloud platform services, you need to create an account by following these steps:

1. Enter **Nimbuscloud.io** in your browser.&#x20;
2. Click the **Sign Up** button.&#x20;
3. Click the **Create an Account** link.
4. Enter the following details in the form:

* **First Name and Last Name**
* **Address**
* **Phone Number**&#x20;
* **Account type (Organisation, Individual)**
* **Password and Confirm Password**

4. Click the **Submit** button.

Your account is successfully created.
