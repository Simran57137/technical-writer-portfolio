# Managing Operations

After creating a virtual machine, you can perform various operations to manage its lifecycle and configuration based on your workload requirements.

You can perform the following operations:

* **Start** a virtual machine to run its workloads.
* **Stop** a virtual machine when it is not required.
* **Restart** a virtual machine to refresh its operating system or services.
* **Reboot** a virtual machine when a restart is required.
* **Delete** a virtual machine when it is no longer required.
* **Manage** the virtual machine's configuration and attached resources.

To manage a virtual machine, follow these steps:

1. Navigate to **Compute > Virtual Machines**.
2. Click the **VM Name** that you want to manage.
3. Click the **Actions** tab.
4. Select the required operation.
5. Review the confirmation message, if displayed.
6. Click the **Confirm** button.

The selected operation is performed on the virtual machine.
