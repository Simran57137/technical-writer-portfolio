# Creating a Virtual Machine

A virtual machine (VM) is a virtualized computing resource that provides processing, memory, storage, and networking capabilities for running applications and workloads in Nimbus Cloud Platform.

You can configure a virtual machine based on your workload requirements by selecting the required compute configuration, operating system, storage, and network settings.

Create a virtual machine when you need to:

* Deploy applications and workloads
* Run operating systems in a virtualized environment
* Allocate compute resources based on workload requirements
* Attach storage and network resources to a workload
* Scale computing resources according to your requirements

To create a virtual machine, follow these steps:

1. Navigate to **Compute > Virtual Machines**.
2. Click **Create Virtual Machine**.
3. Select the **Deployment Zone**.
4. Enter a valid **Virtual Machine Name**.
5. Select the required **Operating System** or image.
6. Select the **Compute Plan** based on your CPU and memory requirements.
7. Select the required **Storage Plan** and configure the storage capacity.
8. Select the **Private Network** and **Subnet Tier** to connect the virtual machine to the network.
9. Review the **Configuration** section.
10. Click **Create**.

The virtual machine is created.
