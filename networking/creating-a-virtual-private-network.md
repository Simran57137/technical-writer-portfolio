# Creating a Virtual Private Network

A virtual private network(VPN) provides an isolated networking environment for connecting Nimbus Cloud resources. It defines the address space and network boundaries that resources use to communicate within the cloud environment.

Each private network can contain multiple network tiers, allowing you to separate workloads according to their connectivity and security requirements.

Create a private network when you need to:

* Isolate cloud workloads
* Define an IP address range for your resources
* Control network traffic between workloads
* Connect cloud resources within the same network environment

To create a VPN, follow these steps:

1. Navigate to the **Networks > Virtual Private Networks** menu.
2. Click the **Create Virtual Private Network** button.
3. Select the **Deployment Zone**.
4. Enter the **Address Space** and **Size** in their respective field.

{% hint style="info" icon="note" %}
You cannot edit the Address Space after creating the VPN.
{% endhint %}

5. Select the **Network Plan**.
6. Enter a valid name in the textbox.
7. Review the **Configuration** section.
8. Click the **Create** button.

The Virtual Private Network is created.
