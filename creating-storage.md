# Creating Storage

Storage provides persistent space for storing application data and files in Nimbus Cloud Platform. You can configure storage based on your capacity and workload requirements.

Create storage when you need persistent storage for applications, virtual machines, or other cloud workloads.

To create storage, follow these steps:

1. Navigate to **Storage > File Storage**.
2. Click **Create File Storage**.
3. Select the **Deployment Zone**.
4. Enter a **Storage Name**.
5. Select the required **Storage Plan**.
6. Enter the required **Storage Capacity**.
7. Select the Protocol Type:
   * **NFS**
   * **SMB**
8. Review the **Configuration** section.
9. Click **Create**.

The file storage is created.
